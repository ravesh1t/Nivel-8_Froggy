# Flexbox entre toda a clase 🐸

Proxecto colaborativo do módulo de **Aplicacións web (2º SMR)** do IES Chan do Monte.

A partir da web [Flexbox Froggy](https://flexboxfroggy.com/#es), cada estudante terá asignado un nivel e deberá crear unha solución propia empregando HTML e CSS, na que reproduza a distribución dos elementos utilizando Flexbox.

O obxectivo é construír entre toda a clase unha web que reúna as solucións dos 24 niveis de Flexbox Froggy e, ao mesmo tempo, aprender a traballar de forma colaborativa con GitHub.

## Estrutura do proxecto

Organicei o repositorio coa seguinte estrutura:

- `index.html`: portada común cos 24 niveis, que xestionarei eu.
- `exemplo/`: exemplo resolto no que explico o funcionamento de `justify-content: flex-end`.
- `niveis/nivel-XX/`: carpeta correspondente a cada nivel, que contén dous ficheiros: `index.html` e `style.css`.

## O teu traballo

1. Resolve o nivel que che asigne na web **Flexbox Froggy**.
2. Accede á carpeta `niveis/nivel-XX/` correspondente ao teu nivel e modifica os ficheiros `index.html` e `style.css` para reproducir o exercicio coa túa propia solución.
3. Utiliza `display: flex` e as propiedades CSS necesarias para resolver o reto. Non empregues posicionamento absoluto para colocar as ras, aínda que podes utilizalo para elementos decorativos, como os nenúfares.
4. Inclúe no HTML o número do nivel, o obxectivo do exercicio e unha breve explicación da solución. Engade tamén comentarios no CSS que expliquen as propiedades utilizadas.
5. Comproba que a páxina funciona correctamente e que o ficheiro `style.css` está enlazado sen erros.
6. Envía a túa contribución ao repositorio común mediante unha **pull request**. Na descrición indica o número do nivel, as propiedades CSS utilizadas e como comprobaches o resultado.
7. Entrega en Moodle a ligazón á túa pull request.

Non inclúas nomes completos, datos persoais nin imaxes extraídas do xogo, xa que o repositorio será público.

## Como participar en GitHub sen instalar ningún programa

Creei un repositorio público en GitHub no que iremos incorporando os exercicios de toda a clase.

Para participar, segue estes pasos:

1. **Crea unha conta en GitHub**, se aínda non a tes, desde [github.com](https://github.com/).
2. **Entra no repositorio do proxecto** a través da ligazón que facilitarei na aula virtual.
3. **Crea a túa copia do repositorio:** pulsa o botón **Fork** e, a continuación, **Create fork**. Deste xeito terás unha copia do proxecto na túa conta.
4. **Localiza o teu nivel:** entra na carpeta `niveis/nivel-XX/` que che asigne.
5. **Edita os ficheiros:** abre `index.html` e `style.css` e utiliza a icona do lapis para modificar o código. Tamén podes subir os ficheiros que preparases previamente no teu ordenador.
6. **Garda os cambios:** pulsa **Commit changes** e escribe unha mensaxe que explique brevemente o que modificaches, por exemplo: `Solución do nivel 05 con Flexbox`.
7. **Envía a túa contribución:** na túa copia do repositorio, pulsa **Contribute → Open pull request**. Comproba que a solicitude vai dirixida ao repositorio principal e describe os cambios realizados.
8. **Entrega a ligazón en Moodle:** copia o enderezo da pull request e entrégao na tarefa correspondente.

Unha vez recibida a túa contribución, revisarei que os ficheiros se poidan integrar correctamente no proxecto común. Se é necesario realizar algún cambio, indicareicho na propia pull request.

Cando estea todo preparado, incorporarei a túa solución ao repositorio principal.

## Publicación da web con GitHub Pages

O proxecto contará cunha web pública na que poderemos consultar os exercicios de toda a clase.

Encargareime da publicación mediante **GitHub Pages**, de xeito que non terás que configurar este servizo na túa conta.

A dirección da web seguirá unha estrutura semellante a esta:

`https://USUARIO.github.io/flexbox-froggy-smr2/`

A medida que vaia incorporando as contribucións, poderemos consultar as solucións dos diferentes niveis desde a portada.

## Resultado final

Ao rematar o proxecto, teremos unha web colaborativa cos **24 niveis de Flexbox Froggy**, cada un desenvolvido por un estudante.

Ademais de practicar HTML e CSS, aprenderás a utilizar GitHub para compartir código, traballar sobre un proxecto común e propoñer modificacións mediante pull requests.

**O reto non consiste só en resolver o teu nivel, senón en contribuír a que entre toda a clase construamos un recurso útil para aprender Flexbox.**
